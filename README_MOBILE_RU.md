# Pulse Arbitrage Agent — мобильная облачная версия

Это веб-приложение, которое можно открыть на Android или iPhone через HTTPS. Оно использует сервер для запросов Pulse API; EXE и постоянно включённый компьютер не требуются.

## Как запустить с телефона

1. Скачай архив исходников из ChatGPT и распакуй его в приложение «Файлы» телефона.
2. В браузере открой https://github.com/new и создай **приватный** репозиторий, например `pulse-agent-mobile`. Не загружай туда ключи API или пароли.
3. В репозитории выбери **Add file → Upload files**, выбери исходные файлы из распакованной папки, сохрани изменения. Если мобильная версия GitHub не позволяет выбрать несколько файлов, включи «Версия для ПК» в браузере.
4. Открой https://dashboard.render.com/ и привяжи свой аккаунт GitHub. Создай **New → Web Service**, выбери этот репозиторий (не Static Site).
5. Выбери Go (или конфигурацию из `render.yaml`). Поля сборки: **Build Command** `go build -o app .`; **Start Command** `./app`. Путь проверки: `/health`.
6. В **Environment Variables** добавь три переменные:
   - `CLOUD_MODE` = `1`
   - `APP_PASSWORD` = длинный, уникальный пароль (не менее 16 символов)
   - `PULSE_API_KEY` = твой API-ключ из Pulse TradeOn
   Опционально `TELEGRAM_BOT_TOKEN` для уведомлений. Все значения вводи **только в Render Dashboard**, не в GitHub и не в ChatGPT.
7. Нажми **Deploy**. После успешной сборки Render выдаст адрес вида `https://<название>.onrender.com`. Это будет твой личный мобильный адрес.
8. Открой адрес на телефоне, при запросе авторизации введи логин **admin** и пароль из `APP_PASSWORD`. В интерфейсе нажми **Сканировать Pulse API**.

## Что доступно на телефоне

- Изменение курса юаня (начальное значение 13,07 ₽ за ¥)
- Коэффициент 0,9025, стоимость от 500 ₽, минимум ROI 10%, не менее 40 продаж за 30 дней
- Выбор CS2/Dota2, страниц поиска, модели цены продажи
- Запуск сканирования, фильтрация и ссылки BUFF/Market
- Дополнительные методы TradeOn API, CSV и Telegram (если настроен)
- Удобные карточки предметов на узком экране

### Безопасность и особенности

- Приложение защищено HTTP Basic Auth; **используй только HTTPS-адрес Render**.
- API-ключ хранится в переменной окружения Render и **не возвращается** в браузер.
- Фильтры после сохранения остаются в `localStorage` текущего браузера. При очистке данных браузера они исчезнут.
- Render Free может «усыплять» сервис после бездействия; непрерывная фоновая проверка **не гарантируется**. Для работы 24/7 нужен сервер без автоматического сна.
- Серверные результаты живут в оперативной памяти и пропадают при перезапуске; CSV сохраняй на телефон.
- Работа с настоящим API пользователя не проверена (ключа у разработчика нет). Возможны лимиты и различия формата данных. Автопокупок нет.
- Никогда не публикуй API-ключ, `APP_PASSWORD`, скриншоты с ними или свой адрес вместе с паролем.

### Технические сведения

Go 1.23+, стандартная библиотека. Официальные адреса Pulse API прописаны в `pulse_live.go` и `extra_api.go`.

Локальная проверка проекта (на компьютере разработчика):

```bash
go test ./...
CLOUD_MODE=1 APP_PASSWORD='very-long-private-password' PULSE_API_KEY='your-key' CLOUD_ALLOW_HTTP=1 PORT=8080 go run .
```

`CLOUD_ALLOW_HTTP=1` предназначен **исключительно для локального тестирования**, не устанавливай его на публичном хостинге.
