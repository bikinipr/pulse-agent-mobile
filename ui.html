Мои продажи · данные Market API

Этот раздел загружает твои объявления из API Market.CSGO и Market.Dota2, а затем сравнивает цены с опубликованными минимальными предложениями. Вручную добавлять предметы не нужно. Агент не размещает объявления и не изменяет их стоимость.

На продаже: —Минимальная цена ниже: —После продажи: —

Ключи аккаунтов читаются самим сервером из MARKET_CSGO_API_KEY и MARKET_DOTA2_API_KEY в Render. После замены ключа сервер автоматически использует новое значение. Если Market вернул 401, автоматические повторные запросы с отклонённым ключом приостанавливаются до его замены или успешной проверки авторизации. Выдавать постоянный API-ключ из браузерной сессии агент не пытается.

Для первой загрузки открой вкладку «Мои продажи».

Для проверки ошибки 401 нажми «Проверить авторизацию Dota 2». Проверка выполняется только по нажатию и делает два безопасных запроса чтения.

«Минимальная цена ниже» означает сравнение обычных предложений по названию, без учёта редкого float или других индивидуальных особенностей. Для безопасности API-ключа запросы к Market API идут через единую очередь: максимум 4 запроса за любую секунду (CS2 + Dota 2, включая получение цен). Это ниже лимита площадки 5 запросов в секунду. Проверка в пределах 2 минут использует серверный кеш. На бесплатном Render непрерывная фоновая работа не гарантируется.

Единое облачное приложение

Открывай этот HTTPS-адрес на компьютере или телефоне из любой сети. На обоих устройствах используется один сервер и общий список результатов. Сканирование запускается здесь, без EXE. Для защиты аккаунта используется пароль хостинга. API-ключ рекомендуется задавать только в переменной окружения PULSE_API_KEY.

На бесплатном сервере приложение может останавливаться после периода бездействия, поэтому непрерывный мониторинг требует постоянно работающего хостинга.

Данные рынка доступны только с действующим ключом Pulse и при наличии API-токенов. Реальную работу с твоим аккаунтом ещё не проверяли. Сигналы — предварительные оценки, не гарантия будущей цены. Автопокупки отсутствуют.

1. Быстрые фильтры

Цена продажи: сравнение минимальной цены и средней за месяц

Осторожная оценка = min(средняя цена за 30 дней; минимальное предложение Market × (1 − уценка/100)). Другие модели могут переоценивать скорость продажи. Доход уже учитывает коэффициент 0,9025.

Фильтры предметов — выбор без ручного ввода

Тип и качество заполняются автоматически из данных Pulse. Пока предметы не загружены, разрешены все типы и качества. Ужесточение фильтров сразу скрывает неподходящие строки. Чтобы увидеть новые варианты после смягчения фильтра, повтори сканирование.

Сохрани изменения на сервере. На другом устройстве нажми «Загрузить с сервера» или обнови страницу.

2. Подключение Pulse TradeOn

Ключ не введён · API-ключ хранится в оперативной памяти и, если включена опция ниже, защищённо сохраняется Windows DPAPI для твоего пользователя. В CSV и логи ключ не добавляется.
Подтверждённые адреса встроены:
GET https://api-pulse.tradeon.space/public-api/item/base-info
GET https://api-pulse.tradeon.space/public-api/item/market-info
Авторизация: заголовок Api-Key. Рынки: Buff / CNY и Tm / RUB.
Оценка расхода: 8 токенов за проверку (при выборе обеих игр, 1 страницы и без MarketInfo).
Telegram-уведомления (необязательно)

При включённой опции токен шифруется Windows DPAPI; в JSON настроек не записывается. Telegram-сеть с твоими реквизитами ещё не проверена.

3. Дополнительные возможности Pulse API

Эти запросы выполняются только по кнопке. Отдельные методы могут расходовать API-токены. Результат отображается ниже и не изменяет автоматически фильтры или цену продажи.

MarketInfo · Карточка предмета

Название, тип, качество, иконка и идентификаторы предмета на торговых площадках. Без цены.

GET · 2 токена по документации
AdvancedInfos · Подробная аналитика

Средние/медианные цены за разные периоды, популярность и более подробные заявки по выбранному предмету.

POST · 2 токена
ItemsHistory · История сделок

Точки истории продаж: цена, количество и время. Полезно для графика и оценки падений.

POST · 7 токенов
CompareBestOffers · Лучшие заявки

Сравнение лучших ордеров покупки/продажи и числа продаж за выбранный период.

POST · 3 токена
Поддерживаемые рынки

Площадки, на которых TradeOn предоставляет данные. Не влияет на формулы агента.

GET · системная информация
Комиссии площадок

Справочные комиссии из TradeOn. Твой коэффициент чистой выручки 0,9025 остаётся ручной настройкой.

GET · системная информация
Стоимость методов

Покажет, сколько API-токенов списывается за каждый метод, чтобы контролировать расход.

GET · системная информация
Валюты

Список поддерживаемых API валют; основные расчёты сейчас используют CNY и RUB.

GET · системная информация
CompareTables · Точное сравнение BUFF → Market (для продвинутой настройки)

Метод сравнивает две площадки по правилам Pulse. Его настройки сложнее, чем обычные фильтры: пока используй собственный JSON по официальной схеме. Обязательные поля: game, currency, firstMarket=Buff, secondMarket=Tm, firstMarketOptions, secondMarketOptions, paginationRequest. Метод выполняется только по кнопке; цена рассчитывается пока через BaseInfos.

POST · 2 токена. Возможны ошибки валидации при неподходящих правилах.
